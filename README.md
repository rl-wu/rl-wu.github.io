# Ruilin Wu

A quiet, single-page personal website built with plain HTML and CSS.

## Updating the site

- Edit personal text and links directly in `index.html`.
- Adjust colors, typography, and spacing in `style.css`.
- Replace `assets/images/profile/avatar.jpg` to update the portrait.
- Push changes to the publishing branch; GitHub Pages serves the files directly.

No package installation or build command is required.
